Read a timestamped resource snapshot of a started runtime.

The snapshot covers the runtime's local adapter host process and its live descendants. It does not wait for a running invocation. It returns [`FabricError::ResourceObservationUnavailable`](../error/enum-fabricerror.mdx#variant.ResourceObservationUnavailable) when the runtime stopped, is stopping, its host exited, or the process table cannot be read, and [`FabricError::ResourceObservationUnsupported`](../error/enum-fabricerror.mdx#variant.ResourceObservationUnsupported) when the environment provider or operating system has no resource reader.
