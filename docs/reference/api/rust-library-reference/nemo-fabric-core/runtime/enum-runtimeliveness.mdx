```rust
pub enum RuntimeLiveness {
    Responsive,
    Unresponsive,
    Exited,
    Unknown,
}
```

Whether NVIDIA NeMo Fabric can reach the adapter host independently of invocation traffic.

## Variants

### `Responsive`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Responsive"}} /></pre>

The adapter process and health control path responded within the deadline.

### `Unresponsive`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unresponsive"}} /></pre>

The process was observed running but its health control path did not respond.

### `Exited`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Exited"}} /></pre>

NeMo Fabric directly observed that the adapter process exited.

### `Unknown`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unknown"}} /></pre>

NeMo Fabric could not establish liveness.
