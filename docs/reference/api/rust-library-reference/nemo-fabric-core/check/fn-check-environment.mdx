Check server or runtime health in the selected environment.

Local runtimes use their authenticated adapter health channel. OpenShell server and runtime checks execute `fabric-agent-ctl check` in the sandbox. Local server checks and other providers return `unsupported_scope`. Timeouts and ownership changes return `unknown` health evidence.
