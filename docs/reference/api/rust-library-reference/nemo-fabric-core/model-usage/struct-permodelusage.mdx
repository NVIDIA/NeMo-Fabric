Normalized usage for one literal model/provider identity.

## Fields

### `model: String`

Source-established accounting model identity. A configured identity requires proof that all included work used that model; an outer requested alias alone is insufficient. This is not served-model provenance.

### `provider: Option<String>`

Literal provider identity when established.

### `tokens: TokenCounts`

Complete normalized token dimensions.

### `observed: TokenCounts`

Available deduplicated observations, possibly incomplete.

### `gaps: Vec<UsageGap>`

Dimension-specific gaps.

### `cost: TokenCost`

Provider-reported and catalog-estimated cost.
