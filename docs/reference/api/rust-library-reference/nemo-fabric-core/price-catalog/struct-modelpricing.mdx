Prices of one model, in `currency` per million tokens.

## Fields

### `provider: String`

Provider that sets the price, such as `anthropic` or `openai`.

### `model_id: String`

Canonical model identifier.

### `aliases: Vec<String>`

Other identifiers of the same model, such as dated snapshots.

### `currency: String`

ISO 4217 currency of the rates. NVIDIA NeMo Fabric estimates cost only from `USD` entries.

### `unit: PricingUnit`

What a rate is charged per. NeMo Fabric estimates cost only from `per_token` entries.

### `rates: Option<TokenPricingRates>`

Flat rates. Ignored when `rate_schedule` is set.

### `rate_schedule: Option<TokenRateSchedule>`

Rates that depend on the number of prompt tokens in a request.

### `prompt_cache: PromptCachePricing`

How the provider counts cached prompt tokens. NeMo Relay uses it to split provider usage; NeMo Fabric prices usage that is already normalized, so it does not read it.

### `pricing_as_of: String`

Date the price was taken from `pricing_source`, as `YYYY-MM-DD` in the bundled catalog.

### `pricing_source: String`

Where the price was taken from, such as the provider's pricing page.
