Bundled-skill selection.

`include` and `exclude` are mutually exclusive, and neither may be combined with `enabled: false`; a `null` list reads as omitted. An empty `include` selects no bundled skills; an empty `exclude` selects all of them.

## Fields

### `enabled: bool`

Whether bundled skills load at all.

### `include: Option<Vec<String>>`

Load only these bundled skills. `None` and `[]` differ.

### `exclude: Option<Vec<String>>`

Load every bundled skill except these. `None` and `[]` differ.
