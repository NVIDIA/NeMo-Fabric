Resolve configuration against an explicit descriptor catalog.

Hosts use this with a catalog read from the selected environment or image, for example one produced there by [`discover_descriptors`](fn-discover-descriptors.mdx). Only the supplied catalog participates: this never scans bundled or installed descriptors or `config.discovery` paths, imports runners, or starts a runtime. Validation and configuration projection match ordinary planning.
