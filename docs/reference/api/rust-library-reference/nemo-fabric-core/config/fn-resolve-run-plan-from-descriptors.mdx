Resolve configuration against an explicit descriptor snapshot.

Hosts use this for metadata read from a selected remote environment or image. Only the supplied inventory participates: this never scans local packages or `config.discovery` paths, imports runners, or starts a runtime. Validation and normalized configuration projection are identical to ordinary planning.
