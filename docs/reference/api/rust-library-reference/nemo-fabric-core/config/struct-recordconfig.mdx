Per-invocation run record settings.

When enabled, core appends a start line, sample lines about every 10 seconds while the adapter host works on the request, and an end line for each local invocation to `<artifact root>/.fabric/<runtime_id>/<invocation_id>/run-record.jsonl`.

## Fields

### `enabled: bool`

Whether to write a run record for each invocation. Requires an artifact root, the `local` environment provider, and a `process` or `python` adapter.

### `exclusive_container: bool`

Whether nothing else runs in the container during an invocation, including other runtimes in the same process, so a rise in the container's out-of-memory kill count reads `sandbox_failed` in the record. Unset means false.
