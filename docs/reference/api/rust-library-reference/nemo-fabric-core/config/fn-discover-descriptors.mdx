Discover every adapter and target descriptor that planning would see.

Uses the bundled and `discovery.local_paths` registry without importing runners, installing dependencies, or starting a runtime. Identical records keep all of their sources; malformed or ambiguous records fail discovery rather than disappearing from the catalog.
