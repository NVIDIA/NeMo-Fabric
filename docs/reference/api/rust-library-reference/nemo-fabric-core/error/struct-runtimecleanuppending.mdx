Cleanup context retained when [`crate::run_plan`](../runtime/fn-run-plan.mdx) cannot finish stopping a runtime.

Retry [`crate::stop_runtime`](../runtime/fn-stop-runtime.mdx) with the original plan and [`Self::runtime`](struct-runtimecleanuppending.mdx#method.runtime). The handle and completed output are deliberately excluded from diagnostic formatting.
