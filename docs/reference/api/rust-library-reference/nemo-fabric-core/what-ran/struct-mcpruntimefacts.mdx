What the harness learned about one MCP server when it connected.

## Fields

### `connected: Fact<bool>`

Whether the harness connected to the server.

### `protocol_version: Fact<String>`

MCP protocol version negotiated with the server.

### `server_name: Fact<String>`

Name the server reports for itself.

### `server_version: Fact<String>`

Version the server reports for itself.

### `tool_names: Fact<Vec<String>>`

Raw tool names the server lists, each bounded by the string length rule. At most 64 names, in sorted order.

### `tool_names_truncated: Option<TruncatedEntries>`

Tool names dropped from `tool_names`, by the adapter's helper or by core. Absent when none was dropped, never `null`.
