Facts about one MCP server.

An entry with origin `harness` is a server the harness reports and the plan does not configure. It has the same shape: its `endpoint` reads `not_applicable` with reason `not_configured`, and runtime facts the adapter did not collect read `unavailable` with reason `not_collected`. Only a `plan` entry must name its transport. An entry of any other origin may leave it out.

## Fields

### `origin: String`

Where the entry comes from: `plan` for a server the plan configures, `harness` for one only the harness reports.

### `transport: Option<String>`

Transport, such as `stdio` or `streamable-http`. Required for a `plan` entry, and optional for any other origin.

### `endpoint: Fact<String>`

Configured endpoint without secrets: the lowercase scheme and host and the port for a network server, or the executable's file name for a `stdio` server.

### `runtime: McpRuntimeFacts`

What the harness learned when it connected, as the adapter reports it.
