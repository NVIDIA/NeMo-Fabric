```rust
pub enum FactState {
    NotApplicable,
    Unsupported,
    CollectionFailed,
    Unavailable,
}
```

Why a fact has no value. A collector picks the first state that matches, in declaration order.

## Variants

### `NotApplicable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NotApplicable"}} /></pre>

The fact cannot exist for this run.

### `Unsupported`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unsupported"}} /></pre>

The adapter or environment provider has no source for the fact.

### `CollectionFailed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "CollectionFailed"}} /></pre>

A source exists, but it failed, timed out, returned an invalid report or never returned.

### `Unavailable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unavailable"}} /></pre>

NeMo Fabric holds no value and no evidence for the other states.
