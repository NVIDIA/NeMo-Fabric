Adapter facts.

## Fields

### `id: Option<String>`

Adapter ID from the plan, when an adapter was resolved.

### `package_version: Fact<String>`

Version of the adapter package, as the adapter reports it.

### `descriptor_fingerprint: Option<Fact<String>>`

Fingerprint `nemo.fabric.adapter_descriptor/v1` of the descriptor contents as authored, `sha256:<hex>`. Core writes it whenever the `adapter` section is present; readers accept its absence from cores that predate it.
