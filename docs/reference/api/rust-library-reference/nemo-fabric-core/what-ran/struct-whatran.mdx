What executed for one invocation.

Every section is present, unless `what_ran_truncated` is present: then the object is a minimal one that the byte budget left with only its schema name and version, and every section may be absent.

Decoding a `WhatRan` directly checks the shape of every section and fact, and that no section is `null`. `RunResult` also checks the schema name and version, that every section is present unless `what_ran_truncated` is, and that every `plan` MCP entry names its transport.

## Fields

### `schema: String`

Schema name, `nemo.fabric.what_ran`.

### `version: String`

Contract version, `v1alpha1`.

### `fabric: Option<FabricFacts>`

NeMo Fabric core that ran the adapter.

### `adapter: Option<AdapterFacts>`

Adapter that ran.

### `harness: Option<HarnessFacts>`

Harness behind the adapter.

### `models: Option<BTreeMap<String, ModelFacts>>`

Model facts keyed by the role names of the plan's `models` settings. At most 16 roles, in sorted key order, each key at most 128 characters.

### `models_truncated: Option<TruncatedEntries>`

Model roles dropped from `models`. Absent when none was dropped, never `null`.

### `mcp: Option<McpFacts>`

MCP server facts.

### `environment: Option<EnvironmentFacts>`

Environment the runtime ran in.

### `what_ran_truncated: Option<TruncatedEntries>`

Present only on a minimal object: every section was dropped to keep the object within 128 KiB, with reason `byte_budget` and a dropped count of 1.
