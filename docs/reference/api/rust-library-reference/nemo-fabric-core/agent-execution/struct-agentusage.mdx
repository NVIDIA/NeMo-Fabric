Normalized model usage reported by an adapter target.

## Fields

### `input_tokens: Option<u64>`

Input tokens consumed by the invocation.

### `cached_input_tokens: Option<u64>`

Cached input tokens consumed by the invocation, when reported.

### `cache_write_input_tokens: Option<u64>`

Input tokens written to the provider prompt cache, when reported.

### `input_tokens_include_cache: Option<bool>`

Whether input_tokens already includes both cached_input_tokens (cache reads) and cache_write_input_tokens (cache writes); absent means unknown. True means both are included and false means both are excluded. When the provider includes only one of the two, the adapter normalizes input_tokens to one of these states before reporting.

### `output_tokens: Option<u64>`

Output tokens produced by the invocation.

### `reasoning_tokens: Option<u64>`

Reasoning tokens produced by the invocation, when reported.

### `output_tokens_include_reasoning: Option<bool>`

Whether output_tokens already includes reasoning_tokens; absent means unknown.

### `total_tokens: Option<u64>`

Total tokens reported by the provider.

### `peak_request_input_tokens: Option<u64>`

Input tokens of the largest single model request in the invocation, including cached and cache-write input, when reported.

### `cost_usd: Option<f64>`

Invocation cost in US dollars when reported by the provider.

### `models: Vec<AgentModelUsage>`

Usage broken out by the model that served the requests; empty when not reported. Each provider and model pair appears at most once, compared case-insensitively.

### `extensions: BTreeMap<String, Value>`

Adapter-owned usage fields.
