One observation of the cgroup containing the adapter host. Its counters include the cgroup's descendants and may include other workloads. Limits cover only visible ancestors; ancestors hidden by namespaces are unknown.

## Fields

### `source: String`

Fixed source identifier, `linux_cgroup_v2`.

### `scope: String`

Fixed scope identifier, `adapter_host_cgroup`.

### `target: String`

Device/inode identity. A different identity invalidates counter deltas.

### `observed_at: String`

UTC observation timestamp.

### `visible_cpu_limit_cores: Measurement<f64>`

Minimum of effective cpuset size and visible ancestor CPU quotas. This is a visible upper bound, not reserved or exclusively usable CPU.

### `visible_memory_limit_bytes: Measurement<u64>`

Minimum memory.max among visible ancestors, in bytes.

### `memory_current_bytes: Measurement<u64>`

Hierarchically accounted memory, distinct from process RSS, in bytes.

### `memory_peak_bytes: Measurement<u64>`

Provider high-water mark in bytes, since cgroup creation or the last external reset. Never an invocation-specific peak.

### `swap_current_bytes: Measurement<u64>`

Current swap usage in bytes.

### `cpu_usage_microseconds: Measurement<u64>`

Cumulative cgroup CPU time, in microseconds.

### `cpu_throttled_microseconds: Measurement<u64>`

Cumulative CPU throttled time, in microseconds.

### `oom_kills: Measurement<u64>`

Cumulative OOM kills in this cgroup hierarchy.

### `pressure_stall_microseconds: BTreeMap<String, Measurement<u64>>`

Cumulative pressure-stall microseconds: cpu_some, cpu_full, memory_some, memory_full, io_some, and io_full.
