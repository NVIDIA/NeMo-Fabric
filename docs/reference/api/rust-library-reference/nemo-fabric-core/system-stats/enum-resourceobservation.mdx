One attempt to observe the adapter host process tree. Missing readings are explicit; an unavailable observation never stands for zero resource usage.

## Variants

### `NotCollected`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NotCollected"}} /></pre>

The process group was explicitly excluded from collection.

### `Available`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Available"}} /></pre>

The process tree was read successfully.

#### Fields

##### `snapshot: RuntimeResourceSnapshot`

Timestamped cumulative counters and instantaneous gauges.

### `Unavailable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unavailable"}} /></pre>

The reader supports this runtime, but could not read its process tree.

#### Fields

##### `reason: String`

Why this observation could not be collected.

### `Unsupported`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unsupported"}} /></pre>

The runtime's provider or operating system has no reader.

#### Fields

##### `reason: String`

Which collection capability is missing.
