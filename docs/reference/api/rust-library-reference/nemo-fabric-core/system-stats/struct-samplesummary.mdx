Resource series retention, reductions, and collection quality. Resource samples remain in the referenced JSONL artifact for interval selection.

## Fields

### `target_interval_ms: u32`

Requested cadence; actual timing is retained in sample offsets.

### `max_samples: u32`

Retention bound, including endpoints.

### `sample_count: u32`

Retained samples, including unavailable readings and endpoints.

### `dropped_samples: u64`

Samples skipped because collection fell behind or retention was full.

### `largest_gap_seconds: f64`

Maximum observed interval between retained readings.

### `collection_seconds: f64`

Total time spent collecting retained observations, including endpoints.

### `truncated: bool`

Whether collection or retention prevented a complete series.

### `diagnostics: Vec<String>`

Safe collection/persistence diagnostics. They never change agent status.

### `samples: Option<ArtifactRef>`

Series artifact, absent when its file could not be created or fully written.

### `cgroup_target_continuous: bool`

Whether retained readings kept one cgroup identity with nondecreasing counters and no gaps over twice cadence. This does not prove exclusivity.

### `resident_memory_bytes: Option<GaugeSummary>`

Adapter-host tree resident-memory reductions.

### `process_count: Option<GaugeSummary>`

Adapter-host tree live-process-count reductions.

### `cpu_time_seconds_estimate: Measurement<f64>`

Estimated CPU counter delta, invalidated by observed resets, missing endpoints, target changes, or collection gaps larger than twice cadence.

### `cpu_percent_one_core: Measurement<f64>`

100% means one fully occupied CPU core; this is not normalized by quota.
