## Use the Starter Notebook

<Steps>
<Step title="Prepare Your Checkout">

The starter notebook uses Hermes Agent from a NeMo Fabric source checkout. Complete [Development Setup](../contributing/setup.mdx) and the supported [Hermes Agent installation](install-hermes.mdx), then provide an [NVIDIA API key](https://build.nvidia.com/). The [notebook setup guide](https://github.com/NVIDIA/NeMo-Fabric/blob/main/examples/notebooks/README.md#prerequisites) explains the notebook's environment and credential prompts.

</Step>
<Step title="Open the Notebook in Jupyter">

From the prepared repository root, run:

```bash
just notebooks
```

Open `01_quickstart.ipynb` and run its cells in order. The notebook constructs the reviewer and supplies this function directly in the request; it does not need to read project files:

```python
def average(values):
    return sum(values) / len(values)
```

</Step>
<Step title="Recognize a Successful Review">

With the notebook's prerequisites available, the run should return status `succeeded`. The review should identify that an empty input list causes division by zero. Wording and suggested fixes can vary; check both the status and the finding. A skipped live cell means a prerequisite is missing, not that a review completed.

The remaining cells demonstrate runtime reuse and optional diagnostics. Notebook [02_variations.ipynb](https://github.com/NVIDIA/NeMo-Fabric/blob/main/examples/notebooks/02_variations.ipynb) explores harness and configuration changes after the first run.

</Step>
</Steps>

## Follow the Python Quickstart

These three connected guides use the same code-review task. Follow them in order; the later guides reuse the configuration from the first. An optional fourth guide moves to the source-checkout OpenShell example:

1. [Install One Harness](quickstart.mdx). Install NeMo Fabric with LangChain Deep Agents, provide model access, and review the function. Keep the resulting `first_agent.py` for the next two guides.
2. [Switch Harnesses](switch-harnesses.mdx). Reuse that configuration to run Deep Agents and Hermes Agent variants, then compare results through the same application interface.
3. [Add Skills and MCP](skills-and-mcp.mdx). Extend the Hermes variant with a review skill and a working local MCP tool, then inspect evidence of its tool calls.
4. [Run in OpenShell (Optional)](openshell.mdx). On a Linux host, run the source-checkout Hermes code-review example in a sandbox.

Start with Python 3.11 or later and an [NVIDIA API key](https://build.nvidia.com/). The second guide adds a separate Python 3.14 environment for Hermes Agent; the third supplies a complete local stdio MCP server. The optional sandbox guide requires a Linux host and a source checkout. Each guide explains its additional setup. For supported platforms and other installation routes, see the [Installation Overview](install.mdx).
