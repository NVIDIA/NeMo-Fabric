Run a code review with NVIDIA NeMo Fabric's [starter notebook](https://github.com/NVIDIA/NeMo-Fabric/blob/main/examples/notebooks/01_quickstart.ipynb). The notebook builds a reviewer with [Hermes Agent](https://github.com/NousResearch/hermes-agent), sends it a small Python function, and inspects the result through the Python SDK. Every agent configuration is defined inline.

## What You Will Do

The notebook guides you through the following sequence. Live model calls require the harness and credentials; the inspection calls do not run the agent.

| Notebook Section | What You Do | What to Look For |
| --- | --- | --- |
| Set up the environment | Prepare the SDK and a separate Hermes environment, then load or securely enter an NVIDIA API key. | The setup reports whether the native extension, adapter interpreter, and key are available for live runs. |
| Describe the agent | Build a typed `FabricConfig` selecting Hermes, an NVIDIA-hosted model, review instructions, and an artifact location. | The configuration identifies the reviewer and its execution settings. |
| Run a review | Call `Fabric.run()` with the function below and inspect the normalized result. | Status `succeeded`, a finding about division by zero for an empty list, and correlation IDs and artifact references. |
| Keep state across turns | Start a runtime, request the review, then ask the agent to fix the issue in a follow-up turn. | The second response uses the earlier review's context. |
| Inspect and diagnose (optional) | Call `plan()` to inspect the resolved configuration and `doctor()` to run preflight checks. | The selected adapter and capabilities, followed by a diagnostic report. Neither call runs the agent. |

The review request includes this function directly; the agent does not need to read project files:

```python
def average(values):
    return sum(values) / len(values)
```

## Before You Start

Prepare the supported source-checkout environment before opening the notebook:

1. Complete [Development Setup](../contributing/setup.mdx) to build the SDK and native extension in a NeMo Fabric checkout.
2. Have Git and [uv](https://docs.astral.sh/uv/getting-started/installation/) available. The notebook's setup cells install the supported Hermes release and adapter in a separate Python 3.14 environment. Refer to [Hermes Installation](install-hermes.mdx) if you need to prepare or select that environment yourself.
3. Create an [NVIDIA API key](https://build.nvidia.com/). Export `NVIDIA_API_KEY`, place it in the checkout's gitignored `.env`, or enter it at the notebook's secure prompt. Keep credentials out of saved notebook cells.

The [notebook setup guide](https://github.com/NVIDIA/NeMo-Fabric/blob/main/examples/notebooks/README.md#prerequisites) provides the environment details. Live execution cells skip when their checked prerequisites are missing; a skipped cell does not demonstrate a completed review.

## Open the Notebook

From the prepared repository root, launch Jupyter using the existing recipe:

```bash
just notebooks
```

Open `01_quickstart.ipynb` in Jupyter and run its cells in order. The file is under `examples/notebooks/` in the checkout. You can also [preview its cells on GitHub](https://github.com/NVIDIA/NeMo-Fabric/blob/main/examples/notebooks/01_quickstart.ipynb) before launching.

## Check Your Results

A successful review reports status `succeeded` and identifies that `average([])` causes division by zero. Wording and suggested fixes can vary; check both the status and the finding. In the multi-turn example, check that the follow-up proposes a correction for the same issue.

The notebook also prints runtime and invocation IDs and artifact information. Its inspection cells show the resolved plan and diagnostic results without making an additional agent request.
