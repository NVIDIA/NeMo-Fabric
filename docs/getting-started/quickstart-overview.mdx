Learn NVIDIA NeMo Fabric by running a small agent task, changing the harness that executes it, and adding skills and tools. Follow these three connected quickstarts in order: each builds on the application and configuration created in the first guide.

1. [Install One Harness](quickstart.mdx). Install NeMo Fabric with LangChain Deep Agents, provide model access, and run a workspace task. Keep the resulting `first_agent.py` for the next two guides.
2. [Switch Harnesses](switch-harnesses.mdx). Reuse that configuration to run Deep Agents and Hermes Agent variants, then compare results through the same application interface.
3. [Add Skills and MCP](skills-and-mcp.mdx). Return to the original Deep Agents configuration and add a local skill and an MCP server connection.

Start with Python 3.11 or later and an [NVIDIA API key](https://build.nvidia.com/). The second guide adds a separate Python 3.14 environment for Hermes Agent; the third requires a stdio MCP server of your choice. Each guide explains its additional setup. For supported platforms and other installation routes, see the [Installation Overview](install.mdx).
