Install the ready-made NVIDIA NeMo Fabric adapter for [Factory Droid](https://factory.ai/), Factory's coding agent. Droid is the harness that executes tasks; the adapter connects it to NeMo Fabric. This guide installs the runtime, adapter, and required Droid CLI and SDK.

The [Factory Droid adapter](../integrations/harness/droid.mdx) requires Node.js 22.19.0 or newer, Factory's supported TypeScript SDK, and a caller-installed Droid CLI:

```bash
pip install nemo-fabric
npm install --global droid@0.233.0
npm install --save-exact @factory/droid-sdk@0.9.1
npm install nemo-fabric-adapters-droid
```

The adapter never installs the Droid CLI at runtime. Refer to the [Factory Droid adapter guide](../integrations/harness/droid.mdx) for supported configuration and discovery.

Continue with the [Factory Droid adapter guide](../integrations/harness/droid.mdx) to configure and run a task.
