Install the ready-made NVIDIA NeMo Fabric adapter for [Hermes Agent](https://github.com/NousResearch/hermes-agent), an open source agent from Nous Research. Hermes Agent is the harness that executes tasks; the adapter connects it to your application through NeMo Fabric.

Hermes Agent 0.20 and later is no longer installable from PyPI. End users must
follow the [Hermes Agent installation guide](https://hermes-agent.nousresearch.com/docs/installation),
then install NeMo Fabric and the bare Hermes adapter into the Python environment
that runs Hermes Agent:

```bash
pip install "nemo-fabric[hermes-agent]"
```

These packages do not install Hermes Agent. Use [Hermes Agent v0.22.5](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.5) with Python 3.14. Hermes supports this interpreter for its current dependency stack; this is not a general NeMo Fabric Python requirement. A separate environment keeps those dependencies apart from your application and other harnesses.

## Install in a Separate Environment

For a complete package-based setup with a pinned Hermes checkout, follow [Switch Harnesses](switch-harnesses.mdx#install-the-second-harness). That procedure creates the Python 3.14 environment, installs Hermes with MCP support from its lockfile, and adds the adapter version matching your application.

## Install from a NeMo Fabric Checkout

For local NeMo Fabric development, run the following from the repository root. The recipe creates `.venv-hermes` and installs Hermes Agent v0.22.5 at commit `bf0203a794a07aac3ff764972ab9087baa4e4f4e`, together with the local runtime and adapter packages:

```bash
just install-hermes-agent
export ADAPTER_PYTHON="$PWD/.venv-hermes/bin/python"
```

For a Relay-enabled Hermes environment, install the adapter's `relay` extra
alongside `nemo-fabric[hermes-agent]`; the generic root `relay` extra does not
include the adapter's TOML writer dependency.

Continue with the [Hermes Agent adapter guide](../integrations/harness/hermes.mdx) to configure and run a task.
