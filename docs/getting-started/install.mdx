Choose an installation of [NVIDIA NeMo Fabric](../about-nemo-fabric/overview.mdx), which lets your application configure and run agent harnesses through a shared interface. This overview helps you select a supported environment and the packages needed to run your chosen harness. The runtime, adapter, harness, and optional telemetry dependencies have separate responsibilities: installing the runtime alone does not install an agent harness.

For a guided first run, start with [Quickstart](quickstart-overview.mdx). Otherwise, check the requirements, choose a deployment scenario and package combination, then open the matching installation guide.

## Requirements and Supported Platforms

### Python Versions

NeMo Fabric supports Python 3.11 through 3.14. Some integrations and adapters have additional requirements. The supported Hermes Agent v0.22.5 release requires Python 3.14; OpenHands and the Harbor integration require Python 3.12 or later.

### Platforms

NeMo Fabric supports the following platforms:

- Linux (x86_64 and arm64)
- macOS (arm64)
- Windows (x86_64)

Harness versions and required native tools differ. Choose a [harness guide](../integrations/harness/overview.mdx) before installing its dependencies. The runtime package does not install every harness.

## Deployment Scenarios

Choose where the runtime, adapter, and harness execute before installing packages.

| Scenario | What runs where | Installation route |
| --- | --- | --- |
| Runtime and harness together | The application, runtime, adapter, and harness share one environment. This is the simplest local setup. | [Install a Complete Runtime and Harness](install-complete.mdx), or [add an adapter to an existing harness](install-existing-harness.mdx) |
| Separate local Python environments | The application and runtime launch an adapter through the interpreter that contains its harness dependencies. | [Install an Adapter and Harness Without the Runtime](install-adapter-harness.mdx), then set `ADAPTER_PYTHON` |
| Isolated task environment | The host constructs configuration; the task environment contains NeMo Fabric, the adapter, and the harness. Discovery and task paths resolve there. | Follow the [Harbor integration](../integrations/consumer/harbor.mdx) or [Environments and Sandboxes](../sdk/environments.mdx) for the chosen deployment |

The runtime and adapter should use matching NeMo Fabric releases unless another combination has been validated. Environment isolation and credential delivery belong to the selected deployment system. For a Hermes task with Relay, install `nemo-fabric-adapters-hermes[relay]` in the Hermes environment; the root Relay extra selects a different Relay release.


## Choose an Installation

The following table shows a representative subset of package expressions and
the components they install. The individual installation guides below describe each route. A **No** entry means that the expression does not
install that component; the component can already exist in the environment or
be managed separately.

| Installation | Runtime | Collector | Adapter | Harness | Relay Python | Relay CLI |
| --- | --- | --- | --- | --- | --- | --- |
| `nemo-fabric` | Yes | No | No | No | No | No |
| `nemo-fabric[streaming]` | Yes | Yes | No | No | No | No |
| `nemo-fabric[relay]` | Yes | No | No | No | Yes | No |
| `nemo-fabric[hermes-agent]` | Yes | No | Yes | No | No | No |
| `nemo-fabric[hermes-agent]` plus `nemo-fabric-adapters-hermes[relay]` | Yes | No | Yes | No | Yes | No |
| `nemo-fabric-adapters-claude[harness]` | No | No | Yes | Yes | No | Yes |
| `nemo-fabric-adapters-claude[full]` | No | No | Yes | Yes | No | Yes |
| `nemo-fabric-adapters-deepagents[full]` | No | No | Yes | Yes | Yes | No |
| `nemo-fabric-adapters-mini-swe-agent[full]` | No | No | Yes | Yes | Yes | No |
| `nemo-fabric-adapters-nooa[full]` | No | No | Yes | Yes | Yes | No |
| `nemo-fabric-adapters-openclaw` | No | No | Yes | No | No | No |
| `nemo-fabric-adapters-openhands` | No | No | Yes | No | No | No |
| `nemo-fabric-adapters-hermes[full]` | No | No | Yes | No | Yes | No |
| `nemo-fabric-adapters-hermes[relay]` | No | No | Yes | No | Yes | No |
| `nemo-fabric-adapters-claude` | No | No | Yes | No | No | No |

An adapter package's `full` extra is scoped to the adapter environment and does
not install the NeMo Fabric runtime. For Claude and Codex, `full` is equivalent
to `harness`; both install the supported harness and `nemo-relay` CLI. For
LangChain Deep Agents and mini-SWE-agent, `full` installs the harness and NeMo
Relay Python package without the CLI. For Hermes Agent, `full` installs the
adapter and Relay Python package; Hermes Agent must be installed separately.
