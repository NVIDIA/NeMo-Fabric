Install the [NVIDIA NeMo Fabric](../about-nemo-fabric/overview.mdx) runtime and an adapter for your chosen harness. Some harnesses require a separate installation. For a guided first run, follow the [Quickstart](quickstart-overview.mdx).

<a id="supported-python-versions"></a>
<a id="supported-platforms"></a>

## Requirements and Supported Platforms

**Python 3.11–3.14.** Linux (x86_64, arm64), macOS (arm64), and Windows (x86_64). Hermes Agent v0.22.7 requires Python 3.14; OpenHands and Harbor require 3.12+. Check your [harness guide](../integrations/harness/overview.mdx) for additional requirements.

Some harness adapters also require Node.js or Bun and separately installed SDKs or CLIs. Follow your harness-specific installation instructions for the required versions.

Compare capabilities on [Supported Harnesses](../about-nemo-fabric/supported-harnesses.mdx); use [adapter installation](install-adapters.mdx) for setup instructions.

## Deployment Scenarios

| Scenario | What runs where | Installation route |
| --- | --- | --- |
| Shared environment | Runtime, adapter, and harness together | [Complete setup](install-adapters.mdx#runtime-and-adapter-together) or [existing harness](install-adapters.mdx#existing-harness-environment) |
| Separate environments | Runtime launches the adapter environment's Python | [Adapter and harness](install-adapters.mdx#separate-python-environments) |
| Isolated task | Runtime, adapter, and harness in the task environment | [Harbor](../integrations/consumer/harbor.mdx) or [Environments](../sdk/python.mdx#explicit-environment-lifecycle) |

An adapter's `full` extra does not install the NeMo Fabric runtime; its contents vary by adapter. Hermes Agent must be installed separately. Refer to [Install a Harness Adapter](install-adapters.mdx) for setup options and dedicated adapter guides.

Use matching runtime and adapter releases unless another combination has been validated. For Hermes telemetry, use the adapter's `relay` extra. Hermes v0.22.7 uses Relay 0.11; v0.22.5 remains supported with Relay 0.10.

### Inspect Adapter Metadata Without Harness SDKs

The optional `nemo-fabric-adapter-catalog` package provides release snapshots of bundled Python and TypeScript adapter descriptors and their registered targets, without installing the runtime or harness SDKs:

```bash
pip install nemo-fabric-adapter-catalog
```

Look up a descriptor by its exact ID; unknown IDs raise `KeyError`:

```python
from nemo_fabric_adapter_catalog import get_adapter_descriptor

descriptor = get_adapter_descriptor("nvidia.fabric.codex")
print(descriptor["config"]["accepts"])
```

Catalog resources do not register execution runners or change task-side discovery. Install actual adapters and harness dependencies separately, and verify snapshot claims against the task's descriptor before relying on them. A catalog package version or fingerprint is not runtime-observed provenance.
