Install the [NVIDIA NeMo Fabric](../about-nemo-fabric/overview.mdx) runtime and an adapter for your chosen harness. Some harnesses require a separate installation. For a guided first run, follow the [Quickstart](quickstart-overview.mdx).

## Requirements and Supported Platforms

**Python 3.11–3.14.** Linux (x86_64, arm64), macOS (arm64), and Windows (x86_64). Hermes Agent v0.22.5 requires Python 3.14; OpenHands and Harbor require 3.12+. Check your [harness guide](../integrations/harness/overview.mdx) for additional requirements.

## Deployment Scenarios

| Scenario | What runs where | Installation route |
| --- | --- | --- |
| Shared environment | Runtime, adapter, and harness together | [Complete setup](install-adapters.mdx#runtime-and-adapter-together) or [existing harness](install-adapters.mdx#existing-harness-environment) |
| Separate environments | Runtime launches the adapter environment's Python | [Adapter and harness](install-adapters.mdx#separate-python-environments) |
| Isolated task | Runtime, adapter, and harness in the task environment | [Harbor](../integrations/consumer/harbor.mdx) or [Environments](../sdk/environments.mdx) |
