Install the ready-made NVIDIA NeMo Fabric adapter for [Cline](https://cline.bot/), an open source coding agent. Cline is the harness that executes tasks; the adapter connects it to NeMo Fabric. This guide installs the runtime, adapter, and required Cline TypeScript SDK.

The [Cline adapter](../integrations/harness/cline.mdx) requires Node.js 22.19.0 or newer and is distributed through npm. Install the NeMo Fabric runtime with pip, then install the supported Cline SDK and adapter in the Node.js project that owns the NeMo Fabric configuration:

```bash
pip install nemo-fabric
npm install --save-exact @cline/sdk@0.0.83
npm install nemo-fabric-adapters-cline
```

The adapter does not declare or install the Cline SDK as a package dependency. Refer to the [Cline adapter guide](../integrations/harness/cline.mdx) to configure adapter discovery and supported capabilities.

Continue with the [Cline adapter guide](../integrations/harness/cline.mdx) to configure and run a task.
