## NVIDIA NemoClaw

[NVIDIA NemoClaw](https://github.com/NVIDIA/NemoClaw) is an open-source reference stack for running supported AI agents inside NVIDIA OpenShell sandboxes.

On its `v1` development branch, NemoClaw uses desired-state configuration to deploy and manage agents. Its NeMo Fabric integration manages agent runtimes across supported harnesses, while NemoClaw coordinates sandbox provisioning, inference routing, and deployment lifecycle.

Select a harness through configuration and use the same deployment workflow to plan, apply, and manage sandboxed agents.

[Explore the upstream integration](https://github.com/NVIDIA/NemoClaw/blob/v1/docs/references/fabric-harnesses.md)

## Harbor Framework

[Harbor Framework](https://github.com/harbor-framework/harbor) is a framework for evaluating and optimizing agents and language models.

Its `FabricAgent` integration lets teams run supported agent harnesses through NeMo Fabric while keeping task provisioning, environments, verification, and scoring in Harbor.

Use the same benchmark tasks to compare harnesses, models, and agent configurations through Fabric’s common execution interface.

[Explore the upstream integration](https://github.com/harbor-framework/harbor/blob/main/src/harbor/agents/installed/fabric.py)

## NVIDIA NeMo Gym

[NVIDIA NeMo Gym](https://github.com/NVIDIA-NeMo/Gym) is a library for evaluating and improving models and agents using task environments.

Its NeMo Fabric integration lets teams run interchangeable agent harnesses while keeping tasks, environments, verifiers, and training workflows in NeMo Gym.

Use the same evaluation environments to compare harnesses and agent configurations, or collect agent rollouts for training.

[Explore the upstream integration](https://github.com/NVIDIA-NeMo/Gym/tree/main/responses_api_agents/nemo_fabric_agent)

## NVIDIA NeMo Helix

[NVIDIA NeMo Helix](https://github.com/NVIDIA-NeMo/nemo-helix) is an open-source control plane for improving and hardening production agents.

Its NeMo Fabric integration translates platform-managed agent definitions into Fabric configuration and runs the selected harness, while NeMo Helix manages deployment, model infrastructure, and evaluation workflows.

Run and compare supported harnesses through NeMo Helix’s agent management and evaluation interfaces.

[Explore agent management](https://docs.nvidia.com/nemo-helix/latest/documentation/studio/agents/) · [Evaluate with a Fabric harness](https://docs.nvidia.com/nemo-helix/documentation/evaluate-models/agent-eval/fabric-runner/)

## NVIDIA NeMo Polar

[NVIDIA NeMo Polar](https://github.com/NVIDIA-NeMo/ProRL-Agent-Server) is a reinforcement learning rollout framework for real-world agent harnesses.

Its NeMo Fabric integration provides a single entry point for selecting and running supported harnesses while NeMo Polar manages runtime preparation, model routing, trajectory capture, and evaluation.

Switch harnesses through configuration while keeping the same task and rollout workflow.

[Explore the upstream integration](https://github.com/NVIDIA-NeMo/ProRL-Agent-Server/blob/stable/src/polar/agent/README.md#nemo-fabric) · [Read the research paper](https://arxiv.org/abs/2605.24220)
