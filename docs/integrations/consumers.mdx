Use NVIDIA NeMo Fabric from your application or through an existing integration to run agents across supported harnesses.

- **[Consumer Integrations](consumer/overview.mdx):** use an existing benchmarking, evaluation, or deployment integration.
- **[CLI (Experimental)](../experimentation/cli.mdx):** explore presets, run examples, and scaffold an application.

For your first run, start with [Getting Started](../getting-started/overview.mdx).
