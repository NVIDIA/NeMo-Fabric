Use an existing framework to benchmark agent harnesses, evaluate configurations, or collect reinforcement learning rollouts through NVIDIA NeMo Fabric. The framework owns the evaluation or rollout workflow; NeMo Fabric runs the selected harness.

| Integration | Use It For |
| --- | --- |
| [Harbor Framework](harbor.mdx) | Compare agents and harnesses on benchmark tasks. |
| [NVIDIA NeMo Gym](gym.mdx) | Evaluate agents in task environments and collect training rollouts. |
| [NVIDIA NeMo Polar](polar.mdx) | Collect reinforcement learning rollouts from agent harnesses. |

For project descriptions and upstream repositories, refer to [Ecosystem](../../about-nemo-fabric/ecosystem.mdx).
