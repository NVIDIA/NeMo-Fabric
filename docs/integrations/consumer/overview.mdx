Use an existing platform or evaluation framework to put NVIDIA NeMo Fabric to work. Choose the outcome your team needs, then follow the product-specific guide. The platform owns its workflow; NeMo Fabric provides supported harness execution where that integration is available.

Helix, Harbor, and Gym provide documented Fabric workflows. NemoClaw provides supported-agent sandbox workflows; Fabric-specific release compatibility is a separate consideration described in its guide. Each product owns its setup and supported package versions.

The [ecosystem overview](../../about-nemo-fabric/ecosystem.mdx) explains how these products divide responsibilities and distinguishes available workflows from emerging integrations.

## Build a Consumer Integration

Use the public NeMo Fabric Python SDK to construct `FabricConfig`, manage the
runtime lifecycle, and consume normalized results and artifacts. Refer to the
[Python SDK guide](../../sdk/python.mdx) for the public integration surface.
