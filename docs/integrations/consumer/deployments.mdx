Use an existing deployment platform to run agents through NVIDIA NeMo Fabric. The platform manages the deployment workflow; NeMo Fabric provides the common interface to the selected harness.

| Integration | Use It For |
| --- | --- |
| [NVIDIA NemoClaw](nemoclaw.mdx) | Deploy and manage agents in NVIDIA OpenShell sandboxes. |
| [NVIDIA NeMo Helix](helix.mdx) | Manage platform-owned agents and deployment workflows. |

For project descriptions and upstream repositories, refer to [Ecosystem](../../about-nemo-fabric/ecosystem.mdx).
