NVIDIA NeMo Fabric connects applications and evaluation systems to the agent harnesses that execute their tasks. A consumer submits work through NeMo Fabric; a harness adapter translates that work into the selected agent's native configuration and execution interface, then returns a common result format.

Use this section to connect an existing system or choose a supported harness. Consumer guides explain how a framework uses NeMo Fabric. Harness guides cover installation, credentials, configuration, and the capabilities each adapter supports. Choose the side that matches your task.
