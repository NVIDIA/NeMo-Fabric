The `nvidia.fabric.langgraph` adapter starts a graph supplied by your Python
factory. Planning validates the selected factory reference without importing
application code. Runtime start imports the factory, passes `workflow.settings`
as keyword arguments, and compiles the returned graph once. Each invocation
then receives the raw NeMo Fabric request input.

## Install

Install the runtime, adapter, and supported LangGraph harness together:

```bash
pip install "nemo-fabric[langgraph]"
```

Or install the adapter in an existing LangGraph environment:

```bash
pip install nemo-fabric-adapters-langgraph
```

To install the adapter and LangGraph without the NeMo Fabric runtime, use:

```bash
pip install "nemo-fabric-adapters-langgraph[harness]"
```

The supported harness constraint is `langgraph>=1.2,<2.0`.

## Select a Factory

Set `workflow.entrypoint.kind` to `langgraph_factory` and use
`workflow.entrypoint.ref` to name an importable factory in `module:attribute`
form. The adapter resolves the module from the agent `base_dir`.

```python
from nemo_fabric import FabricConfig
from nemo_fabric import HarnessConfig
from nemo_fabric import MetadataConfig
from nemo_fabric import WorkflowConfig
from nemo_fabric import WorkflowEntrypointConfig

config = FabricConfig(
    metadata=MetadataConfig(name="review-agent"),
    harness=HarnessConfig(
        adapter_id="nvidia.fabric.langgraph",
        resolution="preinstalled",
    ),
    workflow=WorkflowConfig(
        entrypoint=WorkflowEntrypointConfig(
            kind="langgraph_factory",
            ref="my_agent.graph:build_graph",
        ),
        settings={"prefix": "Review: "},
    ),
)
```

`workflow.settings` becomes keyword arguments to `build_graph`. The factory
returns an uncompiled graph; the adapter calls `compile()` at runtime start.
The compiled graph must implement `ainvoke(input)` or `invoke(input)`.

```python
from typing import TypedDict

from langgraph.graph import END
from langgraph.graph import START
from langgraph.graph import StateGraph


class GraphState(TypedDict):
    input: str
    answer: str


def build_graph(prefix: str):
    graph = StateGraph(GraphState)

    def answer(state: GraphState) -> dict[str, str]:
        return {"answer": f"{prefix}{state['input']}"}

    graph.add_node("answer", answer)
    graph.add_edge(START, "answer")
    graph.add_edge("answer", END)
    return graph
```

The adapter keeps this compiled graph for the complete runtime lifecycle. It
does not import or compile graph code during `Fabric.plan()`.

## Current Capability Boundary

The initial adapter surface is the factory lifecycle. Models, instructions,
tools, MCP servers, skills, and telemetry are not mapped into the factory yet.
Planning rejects those fields for this adapter, so they cannot be configured as
though they were applied. Your graph retains ownership of topology, state,
checkpointers, and application resources.
