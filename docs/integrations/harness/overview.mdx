NVIDIA NeMo Fabric harness integrations are southbound: they connect NeMo
Fabric to agent harnesses through adapters that translate the normalized
contract into harness-native models, tools, sessions, and telemetry.

## Choose a Harness

NeMo Fabric includes the following harness integrations:

| Agent Harness | Guide |
| --- | --- |
| Claude Code | [Use the Claude Code adapter](./claude.mdx) |
| Codex | [Use the Codex adapter](./codex.mdx) |
| Cline | [Use the Cline adapter](./cline.mdx) |
| Factory Droid | [Use the Factory Droid adapter](./droid.mdx) |
| Hermes Agent | [Use the Hermes Agent adapter](./hermes.mdx) |
| LangChain Deep Agents | [Use the LangChain Deep Agents adapter](./deepagents.mdx) |
