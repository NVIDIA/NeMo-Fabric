Contribute to NVIDIA NeMo Fabric itself through the repository's maintainer workflow. Applications using the public SDK start with the [Python SDK](../sdk/python.mdx); third-party adapters start with the [Adapter Contract](../adapter-contract/README.md).

## Before You Contribute

Read the [contribution access and review policy](../../CONTRIBUTING.md#contribution-access). Public issues and comments are welcome; pull request creation requires the repository's approved developer access. Report vulnerabilities through the [security policy](../../SECURITY.md).

- [Development Setup](setup.mdx) covers source builds.
- [Testing and Validation](testing.mdx) identifies relevant checks.
- [Documentation Contributions](documentation.mdx) explains content, navigation, and reference ownership.

The optional [OpenShell provider implementation guide](../../environment-providers/openshell/README.md) documents its existing bridge and lifecycle. Using that provider is covered under [Environments and Sandboxes](../sdk/environments.mdx); this is not a separate top-level integration category.
