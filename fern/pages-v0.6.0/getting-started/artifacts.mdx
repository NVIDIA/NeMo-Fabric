NVIDIA NeMo Fabric distributes Python packages on PyPI, TypeScript packages on npm, and Rust crates on crates.io. The tables below list the packages and link to their registry pages, where you can find available versions and installation details. For installation guidance, refer to [Installation](install.mdx).

## Python Packages on PyPI

The following packages provide the Python SDK, shared contracts, and harness adapters.

| Package | Purpose |
| --- | --- |
| [`nemo-fabric`](https://pypi.org/project/nemo-fabric/) | SDK metapackage that installs the native runtime and offers integration extras. |
| [`nemo-fabric-runtime`](https://pypi.org/project/nemo-fabric-runtime/) | Python SDK, native bindings, and runtime services. |
| [`nemo-fabric-evidence`](https://pypi.org/project/nemo-fabric-evidence/) | Shared software execution evidence types and serialization. |
| [`nemo-fabric-collector`](https://pypi.org/project/nemo-fabric-collector/) | Standalone service that collects and routes NeMo Relay records to runtimes. |
| [`nemo-fabric-adapter-catalog`](https://pypi.org/project/nemo-fabric-adapter-catalog/) | Metadata-only catalog of bundled adapter descriptors. |
| [`nemo-fabric-adapter-contract`](https://pypi.org/project/nemo-fabric-adapter-contract/) | Typed Python contract for adapter implementations. |
| [`nemo-fabric-adapters-common`](https://pypi.org/project/nemo-fabric-adapters-common/) | Shared adapter lifecycle and integration helpers. |
| [`nemo-fabric-adapters-claude`](https://pypi.org/project/nemo-fabric-adapters-claude/) | Claude Code adapter. |

### Native Runtime Wheels

The `nemo-fabric-runtime` package includes native code. Release wheel builds cover the following platforms.

| Operating System | Architecture |
| --- | --- |
| Linux | x86_64, arm64 |
| macOS | arm64 |
| Windows | x86_64 |

Refer to the package's [PyPI files](https://pypi.org/project/nemo-fabric-runtime/#files) for the wheels available for a particular version. Python and harness requirements are described in [Installation](install.mdx).
