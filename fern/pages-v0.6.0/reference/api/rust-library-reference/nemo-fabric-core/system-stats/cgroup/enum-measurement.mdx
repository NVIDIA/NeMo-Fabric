A measured value or its availability. Unlimited is distinct from unknown and is used only for limits. No missing measurement is replaced with zero.

## Variants

### `NotCollected`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NotCollected"}} /></pre>

Its metric group was explicitly excluded from collection.

### `Available`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Available"}} /></pre>

A value was read successfully.

#### Fields

##### `value: T`

Observed numeric value, with units defined by its containing field.

### `Unlimited`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unlimited"}} /></pre>

No limit is configured in the visible hierarchy.

### `Unavailable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unavailable"}} /></pre>

The source could not be read or its counter changed epoch.

#### Fields

##### `reason: String`

Safe reason the reading is unknown.

### `Unsupported`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unsupported"}} /></pre>

The operating system or controller does not expose this measurement.

#### Fields

##### `reason: String`

Missing platform or controller capability.
