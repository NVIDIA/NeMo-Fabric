Check server or runtime health through a supplied environment.

Local runtime checks use the adapter health channel. OpenShell checks use the sandbox command bridge. Local server checks return `unsupported_scope`. Use [`check_service`](fn-check-service.mdx) for registered local services. Timeouts and ownership changes return `unknown` health evidence.
