Install the ready-made NVIDIA NeMo Fabric adapter for [Hermes Agent](https://github.com/NousResearch/hermes-agent). Hermes is the harness that executes the task; the adapter connects it to NeMo Fabric.

## Install the Adapter and Harness

Hermes Agent 0.20 and later is no longer installable from PyPI. End users must
follow the [Hermes Agent installation guide](https://hermes-agent.nousresearch.com/docs/installation),
then install NeMo Fabric and the bare Hermes adapter into the Python environment
that runs Hermes Agent:

```bash
pip install "nemo-fabric[hermes-agent]"
```

These packages do not install Hermes Agent. Use [Hermes Agent v0.22.7](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.7) with Python 3.14. This release includes dependency security fixes absent from v2026.9.24 and supports ordinary runs, Relay 0.11 telemetry, and streaming. For local development, create the isolated environment from the repository root:

```bash
just install-hermes-agent
export ADAPTER_PYTHON="$PWD/.venv-hermes/bin/python"
```

For a Relay-enabled Hermes environment, install the adapter's `relay` extra
alongside `nemo-fabric[hermes-agent]`; the generic root `relay` extra does not
include the adapter's TOML writer dependency.

For a complete separate-environment Hermes v0.22.7 setup, follow [Switch Harnesses](switch-harnesses.mdx#install-the-second-harness). That procedure installs the pinned Hermes checkout with MCP support and the adapter version matching your application.
