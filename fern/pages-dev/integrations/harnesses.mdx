Use an existing NVIDIA NeMo Fabric adapter to run a supported agent harness, or implement the adapter contract to make your custom agent or harness Fabric-ready.

- **[Harness Integrations](harness/overview.mdx):** install, configure, and use existing harness adapters.
- **[Adapter Contract](../adapter-contract/README.md):** build an adapter so applications and evaluation systems can run your agent or harness through NeMo Fabric’s common interface.

To compare available harnesses and capabilities, see **[Supported Harnesses](../about-nemo-fabric/supported-harnesses.mdx)**.
